# Bookstore OOP Lab

## Description

This project demonstrates Object-Oriented Programming concepts in Python through two classes:

### Book

* Stores a book title and page count.
* Validates that page count is an integer.
* Includes a `turn_page()` method that simulates reading.

### Coffee

* Stores coffee size and price.
* Validates that size is Small, Medium, or Large.
* Includes a `tip()` method that increases the price by $1.

## Features

* Class creation
* Constructors (`__init__`)
* Properties and validation
* Methods
* Encapsulation using getters and setters
